# Figures — Data Status & Generation Guide

This folder contains the plotting scripts for every figure in the manuscript.
Each script is documented in its module docstring; this README gives a
**per-figure inventory of which data files are present in `results/`,
which are missing**, and **what to ask the collaborator with GENERator /
Evo2 access to send back**.

All scripts are run from the repo root with the active conda env that has
matplotlib + numpy (any of `generator`, `biojepa`, or the base env work).

```
python scripts/analysis/plot_figureN.py
```

Output PNG + PDF land in [paper/media/](../../paper/media).

All plot scripts share a unified style helper
[scripts/analysis/_figstyle.py](_figstyle.py) which applies the
`apply_style()` defaults (no suptitles, no per-panel titles, sans-serif,
no top/right spines, editable-text PDF) and exposes the `panel_label()`
helper for compact bold A/B/C labels in the corner. Fig 3 additionally
places panel labels in figure coordinates so that labels B/D and C/E
share exact vertical lines despite differing tick-label widths.

## Interpretive note — Evo1 panel F (bf16 vs fp16)

The original fp16 trace (`sw_residual_attribution_evo1.json`) saturates at
~65 k starting at layer 11 and goes to NaN further down. The bf16-clean
trace (`sw_residual_attribution_evo1_fp32.json`) shows the *true* dynamics:

- Row 3776 enters the residual stream around layer 10 with ‖·‖ ≈ 165.
- Layers 11 and 12 write enormous values (≈ 1.2 M and ≈ 1.6 × 10⁷ resp.).
- From layer 13 onward the MLP contribution at row 3776 falls to ≈ 0 and
  the residual freezes at ≈ 3 × 10⁷ for the remaining 20 blocks.
- Per-token argmax shifts away from 3776 by layer 13 (to 3582, 861, 802,
  626, 3279, 1476), so the row is no longer the dominant active channel.

**Interpretation:** the saturated row is a DC offset normalised away by
Evo1's pre-unembed RMSNorm. Ablating it leaves the model output
essentially unchanged (ΔPPL = 0% on the held-out window) — the opposite
of the dispersion/mixer story suggested by the truncated fp16 trace.
Replication on Evo2 is needed to confirm this is a generic StripedHyena
behaviour vs. an Evo1-specific quirk; see
[../../EVO2_REPLICATION.md](../../EVO2_REPLICATION.md).
