# Frozen inputs

Evaluation inputs pinned by content hash so a result can be reproduced without re-resolving
a dataset. Nothing here is generated by this repo's code; these are upstream files copied
verbatim.

## `wikitext_repo/wikitext-2-raw-v1/test-00000-of-00001.parquet`

The WikiText-2 raw **test** split, taken unmodified from the Hugging Face `wikitext` dataset
repo (`repo_type="dataset"`, path `wikitext-2-raw-v1/test-00000-of-00001.parquet`).

```
size    732610 bytes
sha256  5f1bea067869d04849c0f975a2b29c4ff47d867f484f5010ea5e861eab246d91
rows    2891 non-empty lines
```

**Why it is committed.** The E13 census resolved this split through
`datasets.load_dataset("wikitext", "wikitext-2-raw-v1", "test")`, and the frozen path
recorded in `manuscript/experiments/E13_full_cohort_causal_census/run_rowwise_detector.py`
points at a TACC scratch filesystem that does not exist on other machines. Committing the
file lets the text-decoder endpoints run anywhere, offline, on the *same* bytes.

**It is the same file, not a substitute corpus.** `build_windows_local()` in
`scripts/paper_closing/run_uniform_detector_text.py` and
`scripts/paper_closing/run_within_model_slope_text.py` reimplements
`e10_lib.build_windows` against this parquet line-for-line: same non-empty filter, same
`random.Random(42)` shuffle, same fill-to-512-tokens concatenation. Both scripts prefer
`datasets.load_dataset` when it is available and fall back to this file otherwise; the two
paths were verified to produce identical windows by reproducing the census's stored
`baseline_loss` to a relative error of 1.5e-08 on SmolLM2-1.7B.

Override the location with `--wikitext_parquet` or, for the census scripts, the
`E13_FROZEN_WIKITEXT_TEST` environment variable.
